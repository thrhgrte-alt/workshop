# Positive examples (follow these)

Each sheet is a **timeline plot generated from the recipe's own curves** (size, transparency and colour over life, with
lifetime, rate and burst counts), by `scripts/make_examples.py`. They are synthetic demonstrations of the library format,
not renders from Studio and not production effects.

| Sheet | Library id | What to follow |
|---|---|---|
| `arcane_burst.png` | `arcane-burst-purple-001` | Two layers (sparks + flash); quick attack; both fade to fully transparent; 26 particles at peak. |
| `ember_aura.png` | `ember-aura-warm-001` | Steady-state loop with haze and warm light; embers shrink and fade; ~30 particles. |
| `energy_beam.png` | `energy-beam-cyan-001` | One beam, 12 segments, impact sparks at the far end. |
| `sprint_trail.png` | `sprint-trail-blue-001` | Ribbon that narrows and fades; needs a moving part. |

Replace them with your own approved effects in your private library (`RBXVFX_ASSET_ROOT`; see the README). Record the recipe or
Studio place file that produced each one so the *how* is retrievable, not only the look.
