# Examples (all SYNTHETIC)

Every image here is generated by `scripts/make_examples.py` from `visualverify/evalgen.py` with the parameters in the script: flat shapes, gradients, seeded noise.
**None of them is a real render, screenshot or texture.** They exist so the tools can be tried and so the manifest has entries with known properties.

- `shared/`: readable by every project (the knowns: matching and shifted silhouettes, a seamless and a seamed tile, in-range and out-of-range PBR maps, a two-colour palette, a before/after pair).
- `demo-pixel-brawler/`, `demo-realistic-tycoon/`, `demo-stylized-obby/`: one reference each; only that project's tools may read its folder (see `projects.yaml`, `image_roots`).
- `profiles/demo-obby-look.json`: the shape of a saved target profile (numbers only).
- `library/assets.jsonl`: manifest entries (`reference_image`, `measurement_case`, `target_profile`) with the numbers a correct measurement must reproduce; `tests/` checks them against the code.

Try: `python -m visualverify iou examples/shared/cand_shifted.png examples/shared/ref_hero.png --project-id demo-stylized-obby` (IoU 0.6, hand-computed in the manifest).
