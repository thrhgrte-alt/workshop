# Positive examples (follow these)

Generated by `scripts/make_examples.py`. **Synthetic toy economies, not a real game.** The plot shows net income per active minute (log scale) and purchases made over active time for the casual, regular and grinder archetypes.

| Economy | Library id | What to follow |
|---|---|---|
| `examples/economies/balanced.yaml` (`balanced.png`) | `econ-balanced` | Ten tiers; regular-player steps of 10, 10, 10, 20, 30, 40, 60, 80, 100, 120 active minutes (each step costs the current income times the wanted minutes, so income doubles per tier); every step inside its placeholder band; no cost step above 5x; a rebirth loop so content does not run out; a tier-4 choice whose options repay in exactly the same time; boosts at 2.5x. `check_economy` passes with only info findings. |
| `examples/economies/wall_rebalanced.yaml` | `rebalance-wall-001` | The wall toy after `propose_rebalance`: one value changed (drill_4 cost 32000 -> 1920), no new finding. |

`projects/demo_mine/main/economy.yaml` is the same economy registered as a synthetic place. Replace these with your own approved economies in your private projects folder.
