# Positive examples (follow these)

Plan maps generated by `scripts/make_examples.py` from `examples/scenes/*.json` with the synthetic tavern kit. Legend: footprints coloured by module, grey = decor drawn
underneath, green strips = paths, blue lines = sightlines, rings = focal radii, dark outline = locked, red outline = problem.

| Map | Library id | What to follow |
|---|---|---|
| `tavern_corner.png` | see `examples/library/assets.jsonl` | Locked hearth and bar; entrance and bar view kept clear; chairs snapped to tables; mixed sizes; open floor in the middle. Measurements are stored in the manifest and re-checked by a test |

Replace with your own approved scenes in your private library (`SETDRESS_ASSET_ROOT`).
