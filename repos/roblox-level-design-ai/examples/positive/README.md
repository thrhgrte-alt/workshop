# Positive examples (follow these)

Plan maps generated by `scripts/make_examples.py` from the shipped templates; specs live in `examples/levels/*.json`. Synthetic demonstrations of the library format.
Map legend: green door gaps, orange stairs/ramps, triangles = spawns (blue/red team), ring = objective, diamonds = landmarks, line = shortest route with dots
(green: a landmark is in view, red: none).

| Map | Library id | What to follow |
|---|---|---|
| `arena_two_team_loops_001.png` | `arena-two-team-loops-001` | 4 loops, 2 independent routes per team, fairness 1.0, staggered doors (longest sightline 65 studs) |
| `hub_two_team_001.png` | `hub-two-team-001` | One route per team into a central hub; enemy spawns do not see each other |
| `linear_raised_finale_001.png` | `linear-raised-finale-001` | Staggered chain, optional side rooms, 8-stud ramp to a raised finale |

Replace with your own approved layouts in your private library (`RBXLEVEL_ASSET_ROOT`).
